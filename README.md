# Car Price Prediction

This project uses machine learning to predict the selling price of used cars 
based on features like present price, car age, mileage, fuel type, and transmission.

## Tools Used
- Python
- Pandas
- Scikit-learn
- Matplotlib

## How it works
1. Loaded and cleaned a dataset of 301 used car listings
2. Converted categorical features (fuel type, transmission, seller type) into numbers
3. Created a "Car Age" feature from the manufacturing year
4. Split data into training and testing sets
5. Trained a Linear Regression model
6. Evaluated using Mean Absolute Error (MAE) and R² Score
